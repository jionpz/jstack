# 注意力协议：按风险自判介入，问题异步排队，收尾一份摘要

人类注意力是工作流里最贵的资源。route 原来的人类检查点是固定的：歧义任务必有澄清轮，L / XL 必有拆解签字。我们改成按风险判断：只有证据定不了、而且做错代价高的决策才打断人。其余决策先采用默认值，记录下来，在收尾时报告，并写明用户可以怎样改。

- **唯一的"必须停"清单**：取全局红线、poteto-mode 的 Always-pause、route 原有清单三者的并集，只维护一份，route 和门禁 hook 都引用它。
- **由谁判断**：要不要打断人由 premium 判断。依据是可逆性、歧义度、影响面，以及是否命中"必须停"清单。
- **异步提问**：等待回答的 ticket 先挂起，问题进队列（tracker 里打 `needs-human` 标签），通知推到手机；工作继续推进不依赖它的其他 ticket。同一时间攒着的问题合并成一轮问。
- **收尾摘要**：每个任务结束时出一份手机上看得完的摘要，包括目标、改了什么、验证证据、替用户做的决定、需要用户处理的事。

## Consequences

- L / XL 的拆解签字不再是必经检查点，只在 premium 认为拆解有高风险分歧时才请用户确认。
- 用户说"全自动""去睡了"时，仍然遵守"必须停"清单。
- 通知渠道先用 tracker 加 Paseo；渠道是可替换的提供者，不写死在 skill 里。
